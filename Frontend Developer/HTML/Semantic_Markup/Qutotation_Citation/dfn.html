O elemento dfn em HTML representa a instância definidora de um termo. É usado para indicar o local específico onde uma palavra ou frase está sendo definida pela primeira vez em um documento. Normalmente, o termo que está sendo definido está incluído nas tags dfn e, muitas vezes, uma definição ou explicação está na própria página.

The HTML Definition element (<dfn>) is used

Desde o <dfn> elemento não tem title, o conteúdo de texto do <dfn> elemento em si são utilizados como o termo que está sendo definido.
