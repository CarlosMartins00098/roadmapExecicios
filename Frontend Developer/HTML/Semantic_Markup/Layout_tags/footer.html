Link de Referencia

O elemento <footer> em HTML representa um contêiner para conteúdo introdutório ou links de navegação que normalmente aparecem no final de uma seção ou documento. Ele geralmente contém informações sobre o autor, dados de direitos autorais, termos de uso, informações de contato, documentos relacionados e, às vezes, navegação. Um rodapé não está necessariamente restrito à parte inferior da página; ele pode ser usado dentro de seções para denotar o final dessa área de conteúdo específica.
